# SGE - Sistema de Gestão de Estaleiro de Obras

## Trabalho Semestral de Programação Orientada a Objectos

### 1. Apresentação do projecto

O SGE é um sistema desenvolvido em Java para auxiliar na gestão de um estaleiro de obras, permitindo organizar materiais, controlar o stock, registar vendas, gerir trabalhadores, acompanhar obras e administrar pagamentos salariais.

### 2. Objectivo geral

Desenvolver um sistema de gestão de estaleiro de obras, aplicando os princípios de Programação Orientada a Objectos (POO).

### 3. Funcionalidades principais

- Gestão de utilizadores e permissões.
- Autenticação e acesso ao sistema.
- Gestão de materiais e controlo de stock.
- Registo de clientes, vendas e devoluções.
- Gestão de trabalhadores e departamentos.
- Controlo de presenças e férias.
- Pagamento de salários e adiantamentos.
- Gestão de fornecedores e compras.
- Gestão de obras e alocação de trabalhadores.
- Requisição e recepção de materiais.
- Controlo de inventário físico.
- Persistência de dados e auditoria.

### 4. Perfis de utilizador

O sistema contempla três perfis principais:

- **Presidente:** acesso à administração e aos relatórios gerais.
- **Gestor:** gestão das operações do estaleiro.
- **Funcionário:** acesso às funcionalidades autorizadas conforme as suas responsabilidades.

### 5. Tecnologias utilizadas

- Java
- Programação Orientada a Objectos
- Interface gráfica Java Swing
- Git e GitHub
- Persistência de dados em ficheiros

### 6. Conceitos de POO aplicados

- Classes e objectos
- Encapsulamento
- Herança
- Polimorfismo
- Interfaces
- Abstracção

### 7. Organização do desenvolvimento

O projecto foi desenvolvido em colaboração, utilizando branches separadas para organizar as contribuições individuais.

- `main` — versão principal do projecto.
- `Mabessa08` — desenvolvimento de funcionalidades relacionadas com utilizadores, materiais, vendas, interfaces e persistência.
- `samuel` — desenvolvimento de funcionalidades relacionadas com trabalhadores, departamentos, salários, obras e operações do estaleiro.

### 8. Estado do projecto

Projecto académico em desenvolvimento, com as classes distribuídas pelas branches dos integrantes e integração na branch principal ainda por concluir.
