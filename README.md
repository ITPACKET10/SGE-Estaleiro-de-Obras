# SGE - Sistema de Gestão de Estaleiro de Obras

## Contribuições de Mabessa08

**Disciplina:** Programação Orientada a Objectos (POO)  
**Projecto:** Trabalho Semestral — SGE  
**Branch:** Mabessa08

### Objectivo

Desenvolver funcionalidades para a gestão de um estaleiro de obras, aplicando os princípios de Programação Orientada a Objectos, incluindo encapsulamento, herança, polimorfismo e interfaces.

**3. Clientes e vendas**

**4. Interface do sistema**
- TelaLogin.java

**5. Persistência, controlo e auditoria**
- DadosSistema.java
- Arquivo.java
- Auditoria.java

### Funcionalidades

- Autenticação e controlo de acesso dos utilizadores.
- Gestão de materiais e movimentações de stock.
- Registo de clientes, vendas e devoluções.
- Interface de login e navegação.
- Persistência dos dados do sistema.
- Registo e acompanhamento das actividades realizadas.
